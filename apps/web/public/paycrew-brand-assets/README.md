# usePayCrew Brand Asset Package

This package contains editable SVG source assets, PNG exports, favicon sizes, app icons, social assets, and concise brand guidelines.

## Folders
- `logo/`: primary, horizontal, stacked, monochrome, presentation masters
- `icon/`: color, black, white, simplified and app-friendly icon variants
- `favicon/`: 16, 32, 48, 180, 192 and 512 px files
- `app-icons/`: square app icon exports
- `social/`: profile icon, Open Graph image, brand pattern
- `dashboard/`: sidebar and compact mobile assets
- `png/`: rasterized logo/icon exports
- `brand-guidelines/`: palette and usage rules

## Production note
The SVG wordmark uses live text for editability and Arial/Helvetica fallbacks. Before using it as a final registered brand master, choose the approved font and convert wordmark text to outlines in Figma, Illustrator, or Inkscape. Icon geometry is vector path based.
